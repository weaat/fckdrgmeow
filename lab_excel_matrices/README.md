# Лабораторная работа: «Матричные операции в MS Excel»

В этой папке представлены материалы и решения по лабораторной (практической) работе по теме «Матричные операции в табличном процессоре MS Excel».

## Содержимое папки:
1. `Matrix_Lab_Excel.xlsx` (и копия с русским именем `Лабораторная_работа_Матрицы_Excel.xlsx`) — готовая рабочая книга Microsoft Excel со всеми оформленными листами:
   - Лист **Примеры I-VI** — обучающие примеры: МУМНОЖ, сложение, умножение на скаляр, ТРАНСП, МОПРЕД, МОБР.
   - Лист **Задание 1** — самостоятельная работа №1: `3*A*B + (A - B)*(A + 2*B^T)`.
   - Лист **Задание 2** — самостоятельная работа №2: `3*B*(A + B) - |A|*(A^(-1) + 2*B^T)`.
   - Лист **Задание 3** — самостоятельная работа №3: `3*B^T*(A - B) + |B|*(4*A^T + B^(-1))` (с разбором вырожденности матрицы B и двумя вариантами ответа).
2. `index.html` — интерактивная веб-страница с просмотром всех матриц, формул и результатов (доступна через GitHub Pages).
3. `ОТЧЕТ_Матричные_операции_в_Excel.md` — подробный академический отчет с выкладками, промежуточными матрицами и формулами Excel.
4. `build_full_lab.py` — Python-скрипт (openpyxl) для генерации книги Excel.
